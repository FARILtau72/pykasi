omongan asal gas "Bekasi";

Danta / kagadanta

{ } kondisi.bks
# Belum paham? Santai, bre.
danta paham gas Kagadanta;

kalo paham {
    bacot "Gas lanjut!";
} kaga {
    bacot "Tanya dulu, bre.";
}

bacot "Belajar pelan-pelan juga jalan.";
OUTPUT CONTOH↳
Tanya dulu, bre.
Belajar pelan-pelan juga jalan.

Kagadanta bernilai False, jadi cabang kaga yang dijalankan.
